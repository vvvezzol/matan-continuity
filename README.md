# Непрерывность функции

Сайт по математическому анализу для первого семестра: краткая теория и двенадцать задач
на непрерывность с подробными решениями.

**Опубликованная версия:** <https://vvvezzol.github.io/matan-continuity/>

## Разделы

- `/` — обзор, порядок разбора точки разрыва и шпаргалка с пределами;
- `/theory` — восемь разделов теории: предел, непрерывность, односторонние пределы,
  классификация разрывов, техника вычисления пределов, теоремы на отрезке, кусочные функции,
  устранимое продолжение;
- `/solutions` — двенадцать задач с пошаговыми решениями, ответами и примечаниями;
- `/game` — тренажёр-квиз: двенадцать вопросов, объяснения, счёт и локальный рекорд.

## Стек

Next.js 16 (App Router), React 19, Tailwind CSS 4 и KaTeX для формул.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на [http://localhost:3000](http://localhost:3000).

## Проверки

```bash
npm run lint
npm run build
```

## Содержание

Задачи и решения лежат в `src/content/tasks.ts`, теория — в `src/content/theory.ts`.
Формулы записываются в LaTeX: `$...$` внутри текста и `$$...$$` для отдельных выражений.

## GitHub Pages

Сайт собран как статический экспорт. Для публикации под адресом
`https://vvvezzol.github.io/matan-continuity/` сборка использует префикс пути:

```bash
GITHUB_PAGES=true npm run build
```

Готовая папка `out` публикуется в ветку `gh-pages`, откуда GitHub Pages её раздаёт.
